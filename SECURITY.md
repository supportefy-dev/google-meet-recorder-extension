# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's **Security** tab using GitHub Private Vulnerability Reporting. Do not open a public issue for a vulnerability that could expose recordings, microphone access, local files, or extension permissions.

Include:

- A clear description of the impact.
- Steps to reproduce the issue.
- The affected Chrome and extension versions.
- Any suggested mitigation, if available.

Please do not include real meeting recordings, access tokens, or personal information in the report.
